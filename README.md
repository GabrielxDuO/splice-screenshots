# Splice Screenshots

English | [简体中文](./README.zh-CN.md)

A local-first screenshot stitching tool for cropping multiple subtitle screenshots and joining them into one long image. Images are processed in the browser and are not uploaded.

## Features

- Add screenshots in batches or by drag and drop
- Adjust crop handles with live preview
- Use per-image crop or global crop
- Download the joined image
- Chinese / English UI, light / dark themes

## Development

```bash
corepack enable
pnpm install
pnpm dev
```

Common commands:

```bash
pnpm build
pnpm preview
pnpm lint
```
