# Splice Screenshots

[English](./README.md) | 简体中文

一个本地运行的截图拼接工具，适合把多张字幕截图裁切后合成为一张长图。图片只在浏览器内处理，不会上传到服务器。

## 功能

- 批量添加或拖拽导入截图
- 拖动裁切边界，实时预览拼接结果
- 支持单张独立裁切和全局裁切
- 下载拼接后的图片
- 中英文界面、浅色 / 深色主题

## 开发

```bash
corepack enable
pnpm install
pnpm dev
```

常用命令：

```bash
pnpm build
pnpm preview
pnpm lint
```
